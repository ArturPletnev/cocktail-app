# 🍸 SHOWBARMENOV Cocktail App

Веб-приложение для подбора коктейлей к мероприятиям.

## 🚀 Особенности
- Интерактивный квиз из 2-3 вопросов
- Автоматический подбор барного пакета
- Кнопка "Заказать" звонит напрямую по номеру SHOWBARMENOV
- Адаптивный дизайн

## 📁 Структура проекта
- `index.html` - главная страница
- `style.css` - стили
- `script.js` - логика квиза
- `images/` - папка для изображений
